# 路线选择、材料与模型验收

路线描述建模策略。MCP 指工具通道，不代表低多边形、灰模或任何指定美术风格。四条路线都可以导出 GLB。已有模型仅需拍摄宣传片或漫游时，直接读[成片流程](scene-film.md)。只需将已有模型接入 Web 时，跳过重建，直接读 [Web 交付流程](web-delivery.md)。

## 先确认输入能支持什么

先查看当前项目和用户已提供的材料，再提出真正缺失的必需材料。只请求与目标有关的文件；可选材料缺失不阻塞。记录文件、坐标系、单位、稳定对象 ID、来源、阅读状态和不确定性。

|材料类型|先检查与用途|不能据此推断|
|---|---|---|
|DSM/GeoTIFF 高程栅格|读取 CRS、仿射变换、像元分辨率、NoData 和高程单位；为外观准备对应影像或明确使用设计色。可支持地形高度与平面位置。|单幅高程面不能恢复立面、车辆或遮挡物；无影像不能宣称还原真实表面纹理。|
|点云|检查坐标系/单位、RGB、分类、覆盖范围和缺失；选择分区、几何和对象证据。|无坐标或单位时不宣称真实尺度；分类字段不能替代实际读图和空间抽查。|
|OBJ/MTL/纹理|检查 OBJ 几何、索引/UV；核对 MTL 中每条贴图引用与文件存在性、颜色空间和尺寸。|不能假设 MTL 所指图像已加载成功或纹理像素已正确导出。|
|照片、截图、草图|实际打开；标注视角、拍摄时间/方向（如可知）、遮挡和已识别对象。照片可作外观证据或概念参考。|无相机标定/已知尺寸时不推断绝对尺寸；单张照片不能证明背面或隐藏结构。|
|已有 BLEND/GLB/FBX 等模型|实际检查活动场景、可见模型、ID、材质、相机和交付记录；计算内容指纹。|路径、文件名或旧验收状态不能证明当前文件内容未变。|
|文字描述|用于用户定义目标、用途、保留范围和允许的假设。|若没有可比测量/影像，不把概念构造称为实地重建。|

## 四条路线及材料

|路线|适用目标|必需材料|建议材料与可替代来源|缺失时|
|---|---|---|---|---|
|`scan` 扫描保真切分|保留扫描表面与 UV/纹理，只做分区、对象化、必要的清理或碰撞。|扫描几何：已纹理网格/OBJ 及其可用 MTL 贴图，或适用的点云/扫描数据；足以识别要切分部分的实际影像/几何证据。|多视角照片、原始纹理、分区 ID/面映射、相机或测量；可替代的扫描格式须能保留其空间和表面信息。|缺少扫描几何时停止“扫描保真”生产，列出所缺来源并请用户补资料或明确改选路线；只有 DSM 栅格时可做地形，但不能冒充完整扫描场景。|
|`hybrid` 参数化＋选用生成资产|按测量和视觉证据重建规则部分；只对合适对象使用本地/授权生成资产。|清楚的场景范围和目标；对需还原的对象有可读取图像、尺寸/平面/点云之一等足够几何依据。|多视角照片、DSM/点云、已分区模型、实际尺寸、资产来源/许可；生成物可由手工参数化几何替代。|对证据不足对象明确标注缺失/假设；仅在物理目标必须且用户未允许估算时阻塞，不强制等待可选资料。|
|`showcase` 既有模型的展示材质增量|以用户或项目提供的当前模型为基准，先检查并建立本次输入基线，再优化展示材质、色彩分区和局部贴图；几何默认冻结。|用户或项目提供且本次可读取的基准模型及文件 hash；用户要求保留的几何、标识或构图约束。无需另提供历史验收报告；没有记录时本次只读检查并建立基线。|外立面/路面材质照片、色板、目标受众和展示环境；缺少贴图图可使用用户明确允许的纯色或设计材质。|没有基准时，不把新建模型称作材质增量；请用户提供基准或明确改选 `hybrid`/其他路线。若要动几何，先按任务书记录并说明变化。|
|`mcp` 简化空间重建|通过受控 MCP 建模工具快速构造空间关系明确的简化场景。|MCP 工具当前可用且范围匹配；对象清单/布局证据或用户认可的概念假设；明确简化目标。|俯视图、尺寸、照片、点云或已有对象参数；确切尺度缺失时可先用明确标注的估算/相对布局。|工具不可用时报告阻塞或询问是否换工具/路线。没有空间依据时只能做用户认可的概念布局，不称为实地重建。MCP 本身不决定材质或模型精度。|

“必需”指当前路线不可诚实完成的条件，不是要求用户提供所有可能文件。将单个输入的限制写清；例如 GeoTIFF 支持地表高程，但不能补出立面细节。新输入可以是照片、OBJ、点云、地形栅格或文字，不强制先有 GLB 或 manifest。

## 局部迭代

用户对现有场景提出具体反馈时，先从最近可用的 editable 工程、对应导出件和源证据入手。以受影响的对象、相邻接口和用户能看到的机位界定范围。建模前的任务书写清实际差异、可复用产物、正在验证的假设和对应验收。证据齐全时直接推进。

1. **先定位再试改。** 打开源证据和当前输出的对应局部。几何问题先检查构件、方向、尺度和支承，外观问题先检查面归属、UV 和实际绑定的图像。用小范围试片、固定机位近景和必要的剖面快速判断，能从现有源验证的数据优先实测。遮挡处只补完成场景所需的结构，并标注估计。
2. **按失真类型选做法。** 复用资产前对照当前对象可见的轮廓、尺度和特征。依实际问题选读[树木、建筑与滑梯](scene-measurements.md)或[车辆](vehicles.md)的相应条目。只做表面修正时用稳定对象 ID 锁定几何和变换。检查哪些实例引用了要改的网格、材质或图集；若其中只有部分属于修改范围，隔离相应资源再改，核对其余引用者的绑定与外观。
3. **只重跑受影响的步骤。** 改拓扑或变换后复核相邻构件、受影响的 UV 和碰撞；只改材质时先对照确认几何/碰撞未变。用指纹匹配的检查点复用已验证产物，逐轮只渲染能判断当前问题的机位。局部结果满足目标后合入完整场景，用源／旧／新同机位复核关键近景与受影响的全景。
4. **在交付件验收。** 对最终场景运行适用的资产 QA 和独立导出回读，抽查范围外对象。若通行属于目标，或此次几何、障碍或碰撞变化影响已有通路，在所交付的相应网格上复核受影响的入口、平台和出口。纹理按实际嵌入资源检查像素、朝向与绑定。交付 editable 工程时确认可打开，可把默认查看视角对准本轮重点；记录通过、失败、未运行及仍属推定的部分。

## 共用生产阶段与检查点

新建与迭代都按交付目标采用适用阶段。只记录支持本次结论的产物；确实影响结论但缺少证据或未运行的检查，注明其限制。

1. **范围与材料**：记录目的、对象范围、保留内容、目标使用方式、现有输入和缺项；产出任务状态与材料清单。
2. **证据与实例**：按[自主建模时如何发现细节](../SKILL.md#自主建模时如何发现细节)核对本次范围的原始证据与实例，在证据索引或实例清单中记录可辨特征及其去向。保留稳定 `instance_id`、测量或相机记录、源文件指纹、参数、坐标和单位，区分观察、测量、估计、假设、未验证和缺失。物理尺度不明就留空或注明未知。
3. **路线与资产**：记录路线选择、每类对象的方法、可复用资产的来源/版本/参数/hash、对象放置和不确定性；产出建模计划。资产生成和场景摆放分开记。
4. **几何与空间**：以证据建模；相似对象只在几何确实相同时共享；同一连续地表上的道路和铺装可用 Ground 的表面材质表达；有证据的台阶、桥上桥下等不同承托面保留各自的高程与连接；目标需要物理或交互时才建立独立、可检查的碰撞体；纯静态展示可标不适用。产出 editable 场景、参数及适用的碰撞对象。
5. **几何检查点与冻结**：核对 ID、布局及与目标有关的边界或碰撞，按已有输入视角对照。只有单张照片时，注明哪些方向无法从原图验证。使用 Blender 创建或编辑资产后，必须运行适用的 `blender-asset-qa` 并实际打开验收图；单独检查可见破面不等于完整 QA。若 QA skill 不可用，执行入口列出的等价拓扑、法线、退化/重复面、悬浮/穿插、UV/材质和图像检查，并报告覆盖缺口。记录通过/失败/未运行及图像。几何通过后冻结；只有几何/布局变化才使几何及适用碰撞阶段失效。
6. **UV、贴图和语义**：保持对象 ID 和必要分区。使用纹理时检查所用 UV、材质绑定、图像路径和像素；纯色或顶点色表面检查实际使用的材质常量或顶点属性。材质变化只复核受影响的外观与测量。
7. **导出与独立回读**：导出独立 GLB 副本；用不同于导出路径的读回流程检查 scene/node、对象 ID、mesh、材质、纹理引用和像素。截图/目测不能代替像素核查。报告结构检查不等于全面拓扑或应用验收。
8. **视觉验收与交付**：在目标视角/应用检查差异；修正后复查受影响阶段。只交模型时也必须有可打开的 editable 源（若适用）、独立 GLB、纹理读回与实际视觉结果。逐项报告通过、失败、未运行和文件 hash；不要用缓存命中代替验收。

不设通用三角面预算或固定单位比例。若目标设备需要性能预算，先从用户用途/目标设备确定目标，再测量当前资产并记录真实结果。
