# 复用项目已有的流水线

优先读取项目的 AGENTS.md、当前配置、流程文档与既有任务记录。有 docs/pipeline/skill-project-adapter.md 时，先核对它描述的项目、配置和脚本仍与现场一致，再使用其中的路径和案例。

- 调用项目脚本前检查实际帮助和输入输出，尤其是覆盖、清理场景或连接运行中的 Blender 的副作用。以任务目录作工作目录并不自动隔离这些操作。
- 对新模型同时定位能与之对应的源资料、照片及实例清单。项目默认输入可帮助找到旧资产，不能作为新场景的位置、尺度或材质来源。
- 有检查点时核对输入、参数、运行时、上游与实际输出。缓存命中只说明可以复用计算。交付仍需核对当前导出件和适用的视觉、交互或成片结果。
- 若项目的建模入口只列出扫描、重建、材质或 MCP 路线，已有模型拍摄时可直接读取模型并新建拍摄输出目录，不必给建模命令虚构视频参数。
