# 从三维场景拍摄成片

用户要宣传片、漫游或三维结构演示时使用。已有模型就从该版本开始；若任务同时包含建模，先完成影响目标镜头的模型验收。已有可用视频素材且只要求剪辑时，可直接进入合成。

## 确定要展示的空间关系

实际打开当前模型、对应参考图和已有渲染，记录哪些构件、界面或动线最能说明场景。区分参考中真实可见的环境与为了拍摄搭建的配景。核对外部贴图是否可读，桥面、街道、楼层等摄影路径是否连通。对本次目标没有影响的专项检查可以跳过。

按受众与展示渠道选横竖幅、帧率与时长。用简短分镜记录每镜要呈现的内容、摄影机起止位置与注视点、焦距和帧数。长线形场景适合用推进交代连通关系，建筑开口可用侧向移动显示前后遮挡，静态镜头有助于看清复杂构件。根据该场景选镜头数、运动和节奏。用户指定 Remotion 时用它合成；把相机路径、渲染引擎与剪辑软件分别记录。

## 试拍，再渲染

从已核实的 .blend、GLB 或其他源文件工作，使用副本或临时摄影机。按目标画幅试拍运动镜头的起点、中段和终点，并实际查看。轨迹穿过开口、临近护栏或有显著转向时，在该处加拍。检查轮廓裁切、近景穿插、前景遮挡、字幕留白、透明材质、细索闪烁和运动是否符合叙事。若问题来自机位或焦距，先改受影响的镜头；若确需动场景资产，回到建模任务书及对应检查。

冻结机位后，按每镜需要的帧数生成连续画面。在 Blender 中可先写逐帧图像，再以相同帧率封装镜头素材。续跑须确认机位、素材版本、引擎设置与输出一致；参数变化时使用新目录或重算相应镜头。保留可重放的机位参数或关键帧。音画均按同一时间基准剪辑。

## Remotion 合成与交付

已有 Remotion 工程优先复用。新工程可将[随包模板](../assets/remotion-starter/README.md)复制到任务目录，运行 `npm ci`。把本次镜头放入 `public/`，在 `film.json` 填写画幅、帧率、镜头顺序、各段取用帧数，以及需要的标题或配乐。样例仅示范字段。素材中要保留的环境声或对白，须在时间线显式加入；模板默认关闭镜头原声。

在复制出的工程内运行：

```sh
npm run check
npm run still -- out/title.png --frame=15
npm run render -- out/film.mp4
```

试片帧号选在实际片长内。标题位置依实际主体和平台安全区调整；有配乐时核对来源、剪辑点和尾音。需要可编辑交付时保留时间线、锁文件、所引用的本地音画素材和再导出命令；需要改机位时一并保留摄影机数据。发布所用音画须具有相应授权。

## 对最终文件验收

用 FFmpeg 和 FFprobe 读回最终导出件。随包的 [check_film.py](../scripts/check_film.py) 只使用 Python 标准库。以下示例为三镜、共 150 帧的有声竖片，应把参数替换为这次任务实际约定的值：

```sh
python3 "$SKILL_DIR/scripts/check_film.py" out/film.mp4 \
  --width 720 --height 1280 --fps 30 --frames 150 --shots 45,60,45 \
  --audio audible --audio-sync --sheet out/contact.jpg --json out/film-qa.json
```

`SKILL_DIR` 指本技能安装目录。需要无音轨时用 `--audio absent`。镜头帧数决定联系表取样的位置；若时间线含叠化，应按实际成片时间计算覆盖范围。另用目标播放器打开，播放过切点和结尾，查看联系表并核对主体、字幕及声音。画面本来应有摄影机运动但看似静帧时，把最终文件与对应源镜头的同帧画面配对，再检查相隔数帧的结构位置或视差。需要精确同步时核对声画起点及末尾。发现偏差只修受影响的渲染或合成阶段，再读回最终文件。
